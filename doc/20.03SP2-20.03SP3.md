## **2****.** **安装**

### **2.1 列出anaconda中已安装的包名并生成anaconda_list文件：**

dnf --installed list | grep "@anaconda" | grep "arch|x86_64" | awk '{print $1}' | awk -F. 'OFS="."{$NF="";print}' | awk '{print substr($0, 1, length($0)-1)}' > anaconda_list

### **2.2 查询SP3中可用包名并生成all_list文件**

dnf list --available | grep -E "SP3_update|SP3_OS|SP3_everything|SP3_EPOL" | grep "arch\|x86_64" | awk '{print $1}' | awk -F. 'OFS="."{$NF="";print}' | awk '{print substr($0, 1, length($0)-1)}' > all_list

### **2.3**  禁用SP3的源，保持SP2的源为开启状态，在SP2上安装SP3版本中的可用包

dnf config-manager --disable "SP3_everything" "SP3_OS" "SP3_EPOL" "SP3_update" 

yum clean all

dnf install -y $(cat all_list) |tee install_log

```
说明：安装报错时 dnf install -y --skip-broken --nobest  $(cat all_list) |tee install_log 可规避安装冲突问题
```

### **2.4** **启用SP3源**

dnf config-manager --enable "SP3_everything" "SP3_OS" "SP3_EPOL" "SP3_update" 



## **3.** **执行升级**

dnf clean all

dnf install -y $(cat all_list) | tee update_log 

```
说明：安装报错时 dnf install -y --skip-broken --nobest  $(cat all_list) |tee install_log 可规避安装冲突问题
```



## **4.** **重启**

reboot
