## 这是什么？

**mugen** 是 openEuler 社区提供的自动化测试框架，本仓库同时包含**测试框架本体**与**面向 openEuler 操作系统的全量自动化测试用例**。你只需要一个装有 openEuler 的目标机（本地机或 SSH 远端、甚至 QEMU 嵌入式虚拟机），就能用几行命令跑起上千个针对 OS 软件包、命令行工具、系统服务、文件系统、网络、安全、性能特性的用例。

## 🚀 快速开始（30 秒上手）

```bash
# 1. 安装框架依赖（expect/psmisc/make/iputils/python3-paramiko 等）
bash dep_install.sh

# 2. 配置目标测试机（ip/password 必填；--run_remote 表示用例跑到远端 NODE1 上）
bash mugen.sh -c --ip 192.168.1.10 --password 'xxxx' --user root --port 22

# 3. 跑一个用例、一个套件、全部用例
bash mugen.sh -f 测试套名 -r 用例名        # 单用例
bash mugen.sh -f 测试套名                   # 整个测试套
bash mugen.sh -a                            # 全量用例
bash mugen.sh -a -x                         # 调试模式（bash -x）
bash mugen.sh -a -s                         # 全量用例在远端 NODE1 执行

# 4. 查看结果（results 目录按 套件/结果 分目录，每用例一个空文件名标记）
#    logs 目录存每次执行日志
```

> 环境变量 `OET_PATH` 指向仓库根目录；执行入口 `mugen.sh` 已自动设置。
